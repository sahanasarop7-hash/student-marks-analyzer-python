# Student Marks Analyzer

This Python program analyzes student marks and calculates basic statistics.

## Features
- Calculates average marks
- Finds highest marks
- Finds lowest marks

## Technologies Used
- Python
- Lists

## How to Run
1. Run the Python script
2. Enter marks for students
3. The program displays analysis results

## Output Example
Average Marks: 82  
Highest Marks: 95  
Lowest Marks: 65
